# FitLog

A modern workout library application that helps users discover exercises, create workout plans, save workouts, and track completed exercises.

## Technologies Used

* Next.js
* React
* TypeScript
* Tailwind CSS
* Context API
* REST API
* React Icons
* React Toastify

## Key Features

* **Workout Library** — Browse workouts with details such as muscle group, equipment, difficulty, duration, calories, sets, and reps.
* **Personal Workout Plan** — Add exercises to Today's Plan and manage your workout routine.
* **Save Workouts** — Save exercises for later and access them from the Saved section.
* **Mark as Done** — Mark completed exercises to keep track of your workout progress.
* **Workout Sorting** — Sort workouts by duration to easily find suitable exercises.

## Project Goal

FitLog is designed to provide a simple and user-friendly experience for discovering workouts, organizing personal workout plans, saving exercises, and tracking workout progress.
